# 🌍 World Happiness Data Analysis (2015–2016)

This project explores global happiness patterns using the World Happiness Ranking dataset from Kaggle. The goal is to clean, visualize, and interpret socio-economic and health-related factors that influence happiness scores across countries.

## 📁 Dataset Overview

- Records: 314 (157 per year for 2015 & 2016)  
- Columns: Country, Region, Happiness Rank, Happiness Score, Economy (GDP per Capita), Family, Health (Life Expectancy), Freedom, Year

---

## 🎯 Project Objectives

1. Data Harmony – Clean raw data by handling missing values, unrealistic zeros, and outliers.
2. Visual Joy – Build an interactive and insightful Power BI dashboard.
3. The Happy Story – Create a PowerPoint report summarizing findings and dashboard purpose.

---

## 🧹 Data Cleaning Steps

- Replaced zero values in continuous columns (Health, Family, Freedom, Economy) with NaN (likely missing data).
- Removed columns with >90% missing values.
- Investigated extreme outliers (e.g., conflict zones, low-income nations).

---

## 📊 Key Visualizations

- Top 10 Countries by Happiness Score – Horizontal bar chart (Switzerland leads with ~7.60).
- Health-Family Analysis – Table showing regional disparities (e.g., Sudan).
- Year-over-Year Comparison – Bulgaria’s happiness remained stable (~4.22).
- Happiness Score Distribution – Min: 2.84, Max: 7.55, Avg: 5.38.
- Top 10 by Economy – Identical to top happiness countries, highlighting GDP-happiness correlation.

---

## 📌 Key Insights

- Switzerland, Iceland, and Denmark are top happiness performers.
- Economic prosperity strongly correlates with happiness.
- Regional differences exist – e.g., Sub-Saharan Africa shows stronger family support than health metrics.
- Happiness scores remained relatively stable between 2015–2016 for countries like Bulgaria.
